### 1-vocal

- シリコーンの雄型と雌型のボルト締結は，z軸方向が固定されるが，
x, y(左右)軸方向は固定できないものである．by endo

3Dプリンタの造形精度が悪く，穴が大きい場合，ボルト締結を行っても
x, y軸方向が固定されないため，ずれてしまう．
そのため，A型がB型の外形を覆わなければいけない．

- ボルト締結を行う場合は．穴は，ボルトのネジ径より小さく設計し，
穴を穴拡張ドリルを用いて，削る．

- 雌型と雄型で固定要素を作る(マステはあくまでも液体の漏れ防止であるから．)
- 位置合わせをできるようにする(地面に)
- M3をあけるなら→M3.5(クリアランス)
- 型の色合わせ
